# nosleep-mac (`nosleep`)

MacBookのディスプレイ（蓋）を閉じてもスリープさせず、処理を継続できるようにするCLIツールです。  
一定時間が経過すると**自動的にスリープ防止が解除**され、通常の省電力モードに戻ります。

Lucide Icons をベースにしたミニマルで洗練されたデザインを採用しており、**画面下のDock（残り時間バッジ付き）**、**画面右上の通知**、**画面上部のメニューバー**、**ターミナル**のすべてが統一されたクリーンな世界観で動作します。

---

## ✨ デザインと特徴（Lucide スタイル）

1. **絵文字を排除した Lucide スタイルの洗練されたUI**
   - **Dockアイコン**: Lucide の `Moon` アイコンを正確にベクター描画（ダークZinc背景、2.2ptクリーンストローク）。右上のバッジに `29m` と残り時間を表示。
   - **メニューバー**: SF Symbols / Lucide の `Eye`（見守る/アウェイク）テンプレートアイコンを採用。macOSのダーク/ライトモードに美しく馴染みます（残り時間に応じて `AlertTriangle` に変化）。
   - **ターミナル**: 余計な絵文字を排除し、`● ACTIVE`、`▲ WARN`、`■ CRIT`、`[━━━━━━┈┈┈┈]` といったミニマルな記号とタイポグラフィで1行表示。
2. **スクロール・ガタつきゼロの1行固定インプレース更新**
   - 画面が勝手に上に上がっていく現象を物理的に根絶しました。
3. **Macを閉じてもスリープしない（クラムシェル蓋閉じ対応）**
   - `caffeinate` では防げない蓋閉じスリープを、システムレベル（`pmset disablesleep`）で確実に防止します。
4. **自動タイマー解除（戻し忘れ防止）**
   - 指定した時間が経過すると自動で解除されます。
5. **どこからでもワンアクションで解除可能**
   - **ターミナル**: `q` キー または `Ctrl+C`（Enter不要）。
   - **Dock**: アイコンを右クリック →「× スリープ防止を解除して終了」。
   - **メニューバー**: アイコンをクリック →「× スリープ防止を解除して終了」。
   - **別ターミナル**: `nosleep --off` を実行。
6. **時間のワンタッチ延長機能**
   - ターミナルで `+` キーを押すか、メニューから「+ 15分延長」「+ 30分延長」「+ 1時間延長」を選択可能。
7. **バッテリー保護（過放電ガード）**
   - バッテリー駆動中に残量が 10% 以下になった場合、自動的にスリープ防止を解除します。

---

## 🚀 使い方

```bash
# デフォルト (30分間スリープ防止)
nosleep

# 時間を指定して実行
nosleep 15m      # 15分
nosleep 1h       # 1時間
nosleep 1.5h     # 1時間30分
nosleep 90s      # 90秒
nosleep 45       # 45分 (単位なしは分)
```

## 🖥️ 画面表示

### ターミナル
```text
  ● Mac No-Sleep [有効] — 蓋閉じスリープ防止中
    メニューバー、Dock、通知でも状況を確認・解除できます
    操作: [q] 解除  /  [+] 15分延長  /  [Ctrl+C] 終了

  ● ACTIVE  28:45/30:00  [━━━━━━━━━━┈┈┈┈] 65%  │  21:58 終了  │  74% (バッテリー)  │  q: 解除
```
*(※この1行だけがその場で静かに更新されます)*

### ターミナル外
- **画面下の Dock**: Lucideスタイルの三日月アイコンが出現し、右上に `28m` とバッジ表示。右クリックからメニュー操作可能。
- **画面上部のメニューバー**: `eye`（目）アイコンと残り時間が表示。
- **通知センター**: 起動時・残り3分・終了時にクリーンな通知が届きます。
